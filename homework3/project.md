## Project Idea

An idea that I have is to write a small neural network in C++, from scratch. We can use multi-threading frameworks such as OpenMP, since we are all somewhat familiar with this library from the course materials, or we can try to learn and implement high-level frameworks like PyTorch. 

Another idea I had is to parallelize already existing algorithms for puzzles like sudoku. We can try to implement multiple different sudoku solving algorithms (or any other puzzles or games) and parallelize the process using different tools/models.
